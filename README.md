## Getting Started

To run this project locally:

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

## Deployment

This portfolio can be deployed easily on platforms like **Vercel** or **Netlify**.  
Since it uses only HTML, CSS, and JavaScript, no special build step is required [web:2][web:10].

## Customization

You can update the following parts to make it your own:

- Replace personal details in the About section.
- Add or remove projects.
- Update social links.
- Change colors, fonts, and images.
